# 网格伪影排查与修复记

> 时间：2026-09-27 ~ 09-28 ｜ 环境：RTX 5060 Ti 8GB，diffusers `QwenImage21Pipeline`，GGUF Q4/Q5
> 结论：**根因 = VAE 分块解码（tiled decode）的拼接接缝**，已通过 `QWEN_VAE_TILING=auto` 默认策略修复。

## TL;DR

| 问题 | 根因 | 处置 |
|---|---|---|
| 高步数下残留的规则网格线（5×5 淡线） | VAE 分块解码接缝：stride **192px**、blend 64px，1024² 下每轴正好 **5 条** | 文生图 ≤1024 **关闭分块**（auto 默认），接缝彻底消失 |
| 低步数（<12）的细密网格（4~8px） | 模型**非蒸馏**特性，去噪不收敛 | 靠步数解决（≥20，网页已加提示），与分块无关 |
| 换量化（Q4→Q5）无效 | 接缝发生在 **VAE 解码阶段**，与 transformer 量化无关 | 符合预期 |
| 编辑接口 / 1536² 大图 | 分块关闭实测 OOM | 这两类路径**强制保持分块**（auto 策略） |

---

## 一、现象与初始信息过滤

用户报告：出图有规则"5×5 矩阵/网格"，低步数很明显，高步数残留网格边缘残影，Q4 换 Q5 无改善。
同时带来一份网络调研（VAE 缺对抗损失、RoPE 频率竞争、步数过低、LoRA 污染、分辨率 32 对齐、
Tiled VAE 接缝、量化误差、FP8 缩放）。

先做**对号入座**，排除与本服务无关的因素：

| 调研因素 | 本服务情况 | 结论 |
|---|---|---|
| 社区 LoRA 污染 | 服务无任何 LoRA | ❌ 无关 |
| FP8 缩放 | 用 GGUF，非 FP8 | ❌ 无关 |
| 分辨率非 32 倍数 | 默认 1024² 及全部比例表均 32 对齐 | ❌ 主路径无关（自定义怪尺寸仍可能） |
| 步数过低 | 默认 30，官方 40 | ✅ 可测 |
| **Tiled VAE 拼接缝** | 服务**硬编码开了** `pipe.vae.enable_tiling()` | ⭐ 头号嫌疑 |
| VAE/RoPE 模型先天缺陷 | 模型本身，关不掉 | ⚠️ 只能缓解或接受 |

## 二、方法论：先建客观测量，不靠肉眼

肉眼（及模型看图）无法做前后对比的量化，先写了 5 个脚本（已固化在 `scripts/analysis/`）：

| 脚本 | 作用 |
|---|---|
| `grid_detect.py` | 2D FFT 分轴测量：`E_v/E_h`（横/纵线强度）、周期、150~240px **接缝频带**能量 |
| `seam_probe.py` | 在**预测接缝列/行**（192/384/576/768/960 ±3）测平均梯度 vs 全图本底 |
| `band_vis.py` | 频带分离反变换，把细网格/中频网格/接缝三个频带**可视化** |
| `diff_vis.py` | **同 seed 差值隔离**：两图相减，差值即唯一变量的全部影响 |
| `probe_check.py` | 探针偏差校验：查内容几何（如圆边缘 bbox）是否与采样带重合 |

## 三、源码定位：网格几何算出来

`diffusers/models/autoencoders/autoencoder_kl_qwenimage21.py`：

```
tile_sample_min = 256px   tile_sample_stride = 192px   blend = 256-192 = 64px
1024² 图 → latent 64×64（VAE 8× + patchify 2×）
tiled_decode: for i in range(0, 64, 12) → 6 块/轴
→ 每轴 5 条内部接缝，接缝位于图像空间 192/384/576/768/960
→ 6×6 格子、5×5 线 —— 与用户描述的"5×5 矩阵"完全吻合
```

## 四、实验与推理链

### 1. 步数梯度（同 prompt 同 seed=1，分块开）

| steps | 网格强度 grid | 接缝频带 | 主峰周期 |
|---|---|---|---|
| **2** | **158.6** | 27.1 | 4~8px 细网格（采样未收敛） |
| 12 | 20.6 | 5.6 | 8/16px |
| 30 | 16.3 | 6.2 | ~19px |
| 40 | 15.9 | 6.0 | ~19px |

→ 低步数网格是**独立问题**（4~8px，能量爆表）；高步数有 ~15~16 的**不随步数消失的残留**。

### 2. 分块开关 A/B（同 seed，唯一变量 = 分块）

| 指标（steps=30） | 分块开 | 分块关 |
|---|---|---|
| 网格强度 | 16.3 | 14.3 |
| 探针 ratio_x | 1.688 | 1.603 |
| 显存峰值 | 6421 MB | **7752 MB**（+1.3GB，证明开关生效） |
| 耗时 | 111.4s | 97.7s |

指标**几乎没动** → 一度推翻接缝假设。

### 3. 假阳性修正（关键教训）

`probe_check.py` 显示测试图（白底红圆）的 **bbox = x[189–834] y[186–836]，
圆的左边缘恰好压在 192 采样带上**——"接缝梯度集中"其实是圆边缘本身；
步数越高边缘越锐利，还伪装出了"步数效应"。探针结论作废。
同时三频带能量 ON/OFF 差异 <1%（fine 4.687/4.671、mid 7.855/7.804、seam 15.549/15.473）。

### 4. 同 seed 差值隔离（决定性证据）

分块开/关两图 seed、prompt、步数全同 → latent 相同，**差值 = 分块路径的全部影响**：

```
diff: rms=1.320  mean|d|=0.562/255  max=72
接缝带(192k±4) |d| 均值 / 其余列 = 0.711 / 0.556 → 比值 1.279
×72 放大后肉眼可见规则网格线
```

→ **接缝真实存在，但幅度只有 ~1~6 个灰阶**（正常观看近乎不可见）。
用户旧图上"明显的网格"= 接缝在**低步数**（相邻 tile 内容差异大）与平滑背景下被放大。
用户肉眼复核：分块关闭的图"网格几乎不可见" ✅。

### 5. 显存边界测试（能否定为默认的前提）

| 路径 | 分块关 | 结果 |
|---|---|---|
| 文生图 1024² | 7752 MB | ✅ 通过 |
| 文生图 1536² | 解码激活爆炸 | ❌ OOM（HTTP 500） |
| 编辑 1024 | 视觉编码器 + 解码 | ❌ OOM（HTTP 500） |

顺带发现两个工程问题（已修）：
- 权重搬移路径的 OOM 以**泛 RuntimeError** 抛出，`except OutOfMemoryError` 接不住 → 改为按消息 `"out of memory"` 捕获，接入自动降级重试；
- 服务曾以隐藏窗口启动**丢日志**看不到 traceback → 改为 `Start-Process -RedirectStandardOutput/Error` 落盘。

## 五、最终修复：`QWEN_VAE_TILING=auto`

`server.py` 改动：

1. 新增环境变量 `QWEN_VAE_TILING`（`auto` 默认 / `1` 恒开 / `0` 恒关）；
2. `_generate` 内**按请求**设置 `pipe.vae.use_tiling`（GEN_LOCK 串行，翻标志位安全）；
3. OOM 降级重试到 ≤1024 时同步重算分块策略；
4. 响应 `usage.vae_tiling` 字段回报本次实际策略。

```
auto 真值表:
  编辑(有参考图)      → 开（关必 OOM，实测）
  文生图 长边 > 1024  → 开（关必 OOM，实测）
  文生图 长边 ≤ 1024  → 关（消接缝，省 13s）   ← 默认出图路径
```

## 六、验证

| 测试 | `vae_tiling` | 结果 |
|---|---|---|
| 文生图 1024²/30 步 | false | ✅ 98.4s / 7752MB / 网格 14.3 |
| 文生图 1536²/8 步 | true | ✅ 67.9s / 6421MB |
| 编辑 1024² | true | ✅ 247.7s / 8367MB |

- 1536² 分块开后峰值反而只有 6421MB → 反证 1536 的 OOM **发生在解码阶段**，与分块开关吻合；
- 用户终审：默认路径的图（153830）效果最佳；两张 8 步+强制分块的边界测试图网格明显
  —— 低步数网格 + 接缝双重叠加，属**测试设计预期**，非常规用法。

## 七、为什么不是这些（排除项记录）

- **量化档位**：Q4/Q5 同表现，且差值隔离证明接缝是解码侧的 → 与 transformer 量化无关；
- **调度器 shifting / mu**：`_generate` 未传任何 scheduler 参数，且 A/B 证明开关分块即改变结果；
- **RoPE/分辨率周期伪影**：残余 10~30px 频带成分两图一致，用户评估默认出图不可见，未再深究；
- **低步数网格**：模型非蒸馏特性（官方 40 步），只能加步数，网页警告阈值已从 <12 提到 <20。

## 八、遗留边界

1. **低步数（<20）网格仍在**——模型特性，非本次修复对象；
2. **编辑接口与长边 >1024** 必须分块 → 淡接缝（~1~6 灰阶）无法根除，受 8GB 显存硬约束；
3. 关分块后文生图峰值显存 **+1.3GB（7752MB）**——生成时避免再开吃显存的程序；
   必要时 `QWEN_VAE_TILING=1` 可换回恒开（代价是淡接缝）。

## 九、方法论经验

1. **先测量后结论**：FFT/梯度指标先行，肉眼只做终审；
2. **单变量隔离用同 seed A/B**，跨图比较会被内容差异淹没；
3. **探针必须查内容几何重合**——本篇的 1.688"实锤"就是圆边缘压带造成的假阳性；
4. **放大差值图**（×72）能看到亚灰阶的结构性差异，比统计量直观；
5. **改默认前先测边界条件**（1536²/编辑的 OOM 决定了 auto 分支结构）;
6. **用户肉眼是最终标准**，但要给用户**同条件对比组**，避免混入步数/尺寸变量。
